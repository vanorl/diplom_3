## <h>Project: UI Testing "Stellar Burgers"</h>
<h>Покрытие тестами:</h>
## Реализованы проверки следующих пользовательских сценариев:
 ### Основная фукнциональность

✅ Переход по клику на раздел «Конструктор»

✅ Переход по клику на раздел «Лента заказов»

✅ При клике на ингредиент появляется всплывающее окно с деталями

✅ Всплывающее окно закрывается по клику на крестик

✅ При добавлении ингредиента в заказ увеличивается счётчик этого ингредиента

### При создании нового заказа:

✅Счётчик «Выполнено за всё время» увеличивается

✅Счётчик «Выполнено за сегодня» увеличивается

✅Номер заказа отображается в разделе «В работе»

## <h>Инструкция по запуску:</h>

### <h>1. Установить зависимости:</h>

> pip install -r requirements.txt</h>

### <h>2. Запустить тесты с генерацией отчета:</h>

> pytest tests --alluredir=allure-results

### <h>3. Посмотреть отчет</h>

> allure serve allure-results
